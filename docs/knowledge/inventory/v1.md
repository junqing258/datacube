# 多仓库存

按仓库查看可用库存、临期可用库存和缺货商品。

## 指标口径

- **可用库存**为 WMS 快照中可用于履约的库存件数，依照 WMS 的可用量口径。
- **临期可用库存**为快照日期起未来 3 天到期的可用件数。3 天为演示参数。
- **缺货 SKU 数**在单仓内按 SKU 去重。两仓均缺货的同一 SKU 在全局商品数中只计一次。

## 使用规则

先确认仓库、快照时刻和单位。库存为时点数据，跨日累加会重复计算。跨仓比较应使用同一快照时点或标注时间差。

## 常见问题

**哪一仓应优先复核临期库存？** 同时比较临期件数及其占可用库存的比例，再下钻至 SKU 和批次。样例中的一号仓为 720 / 6,000，即 12%。

## 数据映射

来源为 WMS 库存快照。按仓库、SKU、批次和快照时间识别记录。库存接口按参数返回时需声明可用维度与返回粒度。

维护组为仓储运营组。
