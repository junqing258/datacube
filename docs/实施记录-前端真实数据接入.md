# 前端真实数据接入实施记录

日期：2026-11-26。对应方案：[前端真实数据接入方案](前端真实数据接入方案.md)。

## 已交付

首轮销售经营切片已贯通「登录 → 数据集目录 → 图表定义 → 查询执行 → 结果落库 → 看板/收藏读取」，并完成第二阶段的服务端配置持久化。

### 身份与会话

- 邮箱和密码登录，密码以 scrypt 加盐哈希存储；会话令牌随机生成，数据库只保存 SHA-256 摘要。
- 同源 `HttpOnly`、`SameSite=Lax` Cookie 携带令牌，可配置 `Secure`；跨站来源的写请求返回 `403 INVALID_ORIGIN`。
- 闲置 8 小时失效，最长有效期 7 天；`POST /api/auth/refresh` 轮换令牌，`POST /api/auth/logout` 撤销会话。
- 全局守卫校验会话、闲置时间、空间成员资格；成员停用会撤销会话。未登录返回 `401`。
- 只有一个空间时登录后直接进入；多个空间时先选择空间。
- 种子幂等初始化「经营分析空间」、管理员和普通成员，初始口令来自 `SEED_ADMIN_PASSWORD` / `SEED_MEMBER_PASSWORD`。

### 数据集与连接

- `DataConnection.kind` 支持 `sqlite`、`mysql`、`postgresql`。
- SQLite 的绝对文件路径保存在服务端 `settings.path`，只读打开；目录接口不返回路径。
- MySQL 和 PostgreSQL 通过 `secretRef`（`env:` 或 `connections:`）从服务端环境解析只读连接。
- `Dataset` / `DatasetField` 保存表映射、时间字段、字段类型与单位；种子按空间、连接和数据集标识幂等导入 `CHART_DATA_SOURCES`。
- 数据集契约写入 `timeZone=Asia/Shanghai`、`timeFieldFormat`、`amountUnit`、`snapshotTime`（示例库无水位，记录为 `null` 并显示数据时点未知）。
- 示例业务库提供 `sales_daily` 和 `channel_sales_daily` 两个只读视图：退款先按订单汇总再回挂原订单支付日；种子生成「销售额趋势」和「渠道销售额分布」两张真实图表。
- 空间管理员可见全部数据集；普通成员需要 `DatasetGrant`，`FieldGrant` 可进一步限制字段白名单。

### 图表与看板

- `QueryDefinition` 保持不可变：编辑图表时新建查询版本并更新 `Chart.queryId`，旧执行仍可通过外键还原定义。查询版本通过 `QueryDatasetBinding` 按别名记录实际读取的数据集，编辑器保存 JS 图表时提交全部绑定。
- 图表、看板、卡片、收藏、看板版本均存入平台数据库；`localStorage` 的 `datacube.dashboards.v1` 和演示看板不再读取。
- 看板与卡片写入提交 `expectedVersion`，在同一事务内校验版本并递增；冲突返回 `409 DASHBOARD_VERSION_CONFLICT` 和当前版本。
- 卡片使用独立整数位置；批量布局要求提交该看板完整且唯一的卡片集合。
- 复制看板复制布局与筛选映射，沿用图表引用。收藏按用户记录，PUT/DELETE 幂等。
- 图表编辑权限：创建者或空间管理员；其他成员只读。

### 查询执行与结果

- 保存的 SQL 图表由服务端执行；日期窗口通过 `:startDay` / `:endDay` 参数传递，默认 30 天（北京时间的半开区间）；渠道等筛选通过声明参数传递（示例渠道查询的 `:channel` 默认 `all`）。
- SQL 只允许单条 `SELECT` / `WITH` 查询，仅能读取已登记的表或视图，禁止 `ATTACH`、`PRAGMA`、文件读写等操作。
- 执行记录异步运行：`POST /api/charts/:id/executions` 返回 `202`，前端轮询至终态。
- 结果保存到平台 SQLite 的 `QueryResult`，上限 10,000 行 / 10 MiB；超限、超时、失败分别返回 `RESULT_TOO_LARGE`、`QUERY_TIMEOUT`、脱敏错误码。
- 结果默认保留 7 天。`ChartLatestResult` 按图表、查询版本、参数摘要和权限范围记录最近成功执行；刷新失败保留上一次成功指针。
- 结果读取与 CSV 下载重新校验空间、图表和数据集权限；过期返回 `410 RESULT_EXPIRED`；每次读取/下载写入 `AuditEvent`。
- CSV 对文本单元格做公式注入防护。

### 前端

- 登录页、会话身份、空间切换和退出登录；会话每 30 分钟自动续期。
- 首页收藏看板来自服务端；「销售概览」的净销售额、日均、峰值和统计截止来自真实查询结果。
- 看板页的新建、复制、改名、归档/恢复、收藏、添加/移除卡片均调用服务端并处理版本冲突。
- 图表管理的列表、预览、编辑、归档/恢复；编辑页保存 SQL/JS 定义到服务端。
- 图表卡片展示保存查询的最近结果、执行时间、有效期、CSV 下载和口径版本入口；刷新失败时保留上一次结果。
- 数据接入页移除令牌表单，改为当前空间的授权数据集目录；`sessionStorage` 中的 `datacube.chart-data-token` 和 `CHART_DATA_TOKEN` 校验路径已下线。
- JS 图表的 `query.sql` / `extract.js` / `transform.js` 取数仍由浏览器执行，但定义、图表引用和看板配置由平台保存。

## 接口

| 能力                                 | 接口                                                                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 登录 / 会话 / 续期 / 登出 / 切换空间 | `POST /api/auth/login`、`GET /api/auth/session`、`POST /api/auth/refresh`、`POST /api/auth/logout`、`POST /api/auth/space` |
| 数据集目录                           | `GET /api/datasets`、`GET /api/datasets/:id`                                                                               |
| 图表                                 | `GET/POST /api/charts`、`GET/PATCH /api/charts/:id`                                                                        |
| 看板                                 | `GET/POST /api/dashboards`、`GET/PATCH /api/dashboards/:id`                                                                |
| 卡片                                 | `POST /api/dashboards/:id/cards`、`PATCH/DELETE /api/dashboards/:id/cards/:cardId`                                         |
| 批量布局 / 复制 / 收藏               | `PATCH /api/dashboards/:id/card-layout`、`POST /api/dashboards/:id/copies`、`PUT/DELETE /api/dashboards/:id/favorite`      |
| 查询执行                             | `POST /api/charts/:id/executions`、`GET /api/query-executions/:id`                                                         |
| 结果读取与下载                       | `GET /api/query-executions/:id/result`、`GET /api/query-executions/:id/result/download`                                    |
| 浏览器 JS 取数                       | `GET /api/chart-data/sources`、`POST /api/chart-data/read`（改为会话守卫）                                                 |

同时清理了此前未提交的空迁移目录，`prisma migrate deploy` 可按顺序应用。容器启动时先执行迁移，再幂等运行种子；生产环境须配置 `SEED_ADMIN_PASSWORD` / `SEED_MEMBER_PASSWORD`。

## 本地验证

```bash
pnpm business:sample
pnpm prisma:migrate
pnpm prisma:seed
pnpm dev
```

已在示例业务库和两个浏览器会话上验证：

- 两个账号登录；跨会话读取同一已授权看板，结果与业务库视图一致（30 天净销售额趋势、按渠道汇总，独立 SQL 对数一致）。通过 `parameters.channel` 可得到单渠道结果。
- 收藏按用户隔离；普通成员编辑看板返回 `403`；撤销数据集授权后读取结果返回 `404`。
- 两次同版本看板写入返回 `409` 与当前版本；复制、批量布局、卡片增删和收藏幂等重试通过。
- 未登录访问返回 `401`，执行提交返回 `202`，结果过期返回 `410`（读取与下载一致）。
- 图表保存后生成新的查询版本，看板重新执行成功；归档图表后卡片显示已归档。
- 空结果、查询失败、数据连接异常、结果过期和刷新失败都有独立状态；刷新失败保留上一次成功结果。
- `pnpm type-check`、`pnpm lint`、`pnpm test` 通过；新增密码和查询参数单元测试。
